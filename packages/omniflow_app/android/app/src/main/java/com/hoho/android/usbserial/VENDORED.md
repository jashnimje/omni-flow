# usb-serial-for-android 3.8.1, vendored

The `driver` and `util` packages of https://github.com/mik3y/usb-serial-for-android at tag v3.8.1, unchanged, under its MIT licence (LICENSE.txt). `BuildConfig.java` stands in for the library's generated class. Vendored because the published artifact is on JitPack, which the build cannot reach, and the `usb_serial` Flutter plugin no longer builds with Gradle 9.
